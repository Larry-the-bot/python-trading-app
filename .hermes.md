# trading-python-app

Shared desk for Hermes (this profile) and the **price-monitor** profile.

## Trade book

Canonical state machine: `desk/trade_book.json`

- Poller updates quotes and advances `state` (`watching` / `buy_ready` /
  `open` / `sell_ready` / `disabled`). It never fills an order.
- Operator sets `buy_price`, `sell_price`, `instrument`.
- Executor marks a fill with `position=long` and an exit with `position=flat`.
- Buy/sell triggers are on the **underlying**. The traded thing is
  `instrument` (equity option, or crypto `kind=leveraged`).
- Do not arm from a stale/closed equity print. Do not invent contracts.
- Cap 10 enabled names. Match `data/watchlist.txt`.

See `desk/README.md` for the transition table.

## Code

- Observe-only poller: `src/price_monitor.py` (do not rewrite if it exists).
- Live stream (cron `price-poller`): `src/price_stream.py` writes the book from the public Yahoo quote websocket. Do not also run `price_monitor.py --once` — it overwrites a newer stream print with the Robinhood close. Closed equity stays `stale=true`.
- Poller health: `src/monitor_poller.py`.
- Latched buy/sell gate: `src/state_monitor.py` (cron: `state-monitor.py`).
- Trade book helpers: `src/trade_book.py`.
- Playbook (thesis / zone / one core): `src/playbook.py`, `desk/playbook.json`.
- Telegram desk snapshot: `src/telegram_desk.py` (observe only).
- Executor (cron 1m state machine + agent caller): `src/trade_executor.py`
- Trading agent interface: `src/trading_agent.py` (DryRunAgent by default; pluggable for real brokers).
- Optional: max pain calculation (used only when developing playbook levels for new watchlist items): `src/max_pain.py`.

The trade book (`desk/trade_book.json`) is the live state machine.
state_monitor gates; executor acts and calls agent when conditions met (price levels + playbook).

Run tests with `.venv/bin/pytest` before calling a change done.
